# Make Knowledge Cards

将用户粘贴的文章，或用户指定的本地 `.md` / `.txt` 文件，整理成可复习的知识卡片。目标是保留真正重要、可独立学习的知识，而非逐段改写原文。

## 输入与边界

- 先确认输入是粘贴文本或本地 Markdown/TXT；读取本地文件前使用其明确提供的路径。无法读取、为空或内容不足时，说明原因。
- 不抓取网页，不处理 PDF，不导出 Anki，也不创建图形界面。遇到这些需求，简要说明本 Skill 暂不支持的范围。
- 只根据原文作答。不要补充背景事实、推测作者意图，或把常识当成原文信息。

## 提炼方法

1. 通读内容，找出主张、定义、机制、流程、因果关系、关键区别和可迁移的方法；忽略寒暄、修辞、重复表述与无实质信息的过渡句。
2. 将同一概念的重复说明合并。每张卡只讲一个能独立回答的问题；若两点必须彼此依赖才能成立，可放在同一张卡中并明确关系。
3. 优先选择对理解全文最关键、最容易混淆或最具复用价值的点。通常生成 5–8 张；短文或信息密度低时少于 5 张，绝不为了凑数拆碎概念或编造内容。
4. 每张卡必须能在原文中找到依据。例子仅可复述、压缩或改写原文已有的例子；原文没有例子时写“原文未提供例子”。自测题应只考查该卡的原文信息。

## 输出格式

先用一句话说明共提炼了多少张卡（内容不足时也说明未凑数量），然后按下列结构输出。语言跟随用户或原文；默认使用中文。

```markdown
### 卡片 1：<简短、具体的标题>
**核心知识：** <一个准确的知识点或关系>

**简明解释：** <用自己的话说明，保留必要条件、范围或因果关系>

**例子 / 自测：** <原文中的例子；若无则一个只基于原文的自测问题，或说明原文未提供例子>
```

输出前检查：标题不重复；相邻卡片不在讲同一件事；每卡只有一个中心点；所有断言均受原文支持；卡片数量与信息量相称。
