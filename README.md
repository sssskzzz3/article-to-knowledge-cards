# make-knowledge-cards

一个 Codex Skill，用于把文章提炼为可复习的知识卡片。Skill 位于 [`skills/make-knowledge-cards`](skills/make-knowledge-cards)。

## 项目解决什么问题

阅读文章后，关键信息往往分散、重复，难以快速复习。本项目将用户粘贴的文章或指定的本地 Markdown/TXT 文件压缩为结构一致的知识卡片，帮助用户抓住可独立学习的核心知识点。

卡片仅依据原文生成：不会补充原文没有的事实，也不会为了达到固定数量而把同一个概念拆散或编造内容。

## 主要功能

- 从粘贴文本或本地 `.md`、`.txt` 文件中提炼知识。
- 优先保留定义、机制、流程、因果关系、关键区别和可迁移的方法。
- 合并重复表述，确保一张卡片只围绕一个知识点。
- 每张卡片包括标题、核心知识、简明解释，以及原文例子或基于原文的自测题。
- 通常生成 5–8 张卡；短文或信息不足时减少数量，并明确说明不会凑数。
- 所有结论可追溯到输入原文。

当前不支持网页抓取、PDF、Anki 导出或图形界面。

## 安装方法

将此项目中的 Skill 文件夹复制到 Codex Skills 目录：

```text
<Codex Skills 目录>/make-knowledge-cards/
├── SKILL.md
└── agents/
    └── openai.yaml
```

需要复制的源目录是：

```text
skills/make-knowledge-cards
```

安装完成后，在 Codex 对话中通过 `$make-knowledge-cards` 调用。

## 使用方法

### 粘贴文章

```text
使用 $make-knowledge-cards 将以下文章整理为知识卡片：
<粘贴文章正文>
```

### 读取本地文本文件

提供明确的本地 `.md` 或 `.txt` 文件路径：

```text
使用 $make-knowledge-cards 阅读 <本地文件路径>，并生成知识卡片。
```

## 输入输出示例

输入：

```text
间隔重复指在接近遗忘时复习。每次成功回忆都会让记忆更持久。
复习间隔应随掌握程度增加，而不是一直固定。作者没有给出具体天数。
```

输出：

```markdown
共提炼 2 张知识卡片；原文信息量有限，未强行凑到 5 张。

### 卡片 1：间隔重复的复习时机
**核心知识：** 应在接近遗忘时复习。

**简明解释：** 这种安排利用了即将遗忘的时点来巩固记忆。

**例子 / 自测：** 自测：间隔重复建议在什么时候复习？

### 卡片 2：复习间隔应逐步拉长
**核心知识：** 随掌握程度提高，复习间隔应增加。

**简明解释：** 原文不建议始终使用固定的复习间隔，也未提供具体天数。

**例子 / 自测：** 自测：原文是否规定了固定的复习天数？
```
